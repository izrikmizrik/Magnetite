## 1. Мод-хуки: рантайм, host-интерфейс, кодоген

**Рантайм.** Два таргета одного API: нативные моды (собирает лаунчер) и WASM (`mod.wasm`) — `crates/horizon-mod-api/src/lib.rs:1-10`. WASM-движок: `wasmtime = "50"`, features `cranelift` **и** `pulley` одновременно — `crates/horizon-mod-wasm/Cargo.toml:22`. Конфиг движка: `crates/horizon-mod-wasm/src/runtime.rs:155-190` — `epoch_interruption=true`, `wasm_threads=false`, `shared_memory=false`, стек гостя из `horizon-guest-stack`; явного выбора `Strategy` нигде нет (grep по `Strategy::` в мод-крейтах — пусто), т.е. Cranelift по умолчанию, Pulley как запасной интерпретатор (комментарий `runtime.rs:159-161`)._epoch-тикер: отдельный поток `runtime.rs:193-207`.

**Единый источник правды — уже есть.** Каталог хуков: `crates/horizon-mod-vocab/src/hooks/*.rs` — **738 файлов-деклараций**, которые никогда не компилируются (`#[cfg(any())]`), а читаются `syn`-ом генератора `horizon-mod-api-gen` (`crates/horizon-mod-api-gen/src/lib.rs:1`). Грамматика: `crates/horizon-mod-vocab/src/hooks/mod.rs:1-52`:
- `#[hook(side, contract = listen|cancel|collect|replace, out, scope/key (Part), answered_by, owner, isolate, host/context, neoforge/fabric/paper, version, target)]`;
- новый хук = новый файл, генератор находит файлы сам, общий список не редактируется; `cargo run -p xtask -- mod-api` заполняет диспатч; JSON-каталог (`native-hooks.json`) упразднён и ломает сборку;
- host-методы пишутся вручную по областям в `crates/horizon-mod-vocab/src/host/<area>.rs` с `#[access(...)]`; игра реализует одноимённый метод `Game` без префикса `native_`.

**Кодогенерация в OUT_DIR:** API мода — `crates/horizon-mod-vocab/src/lib.rs:12-25` (`mod_api_generated.rs`, `mod_api_generated_host.rs`, `wire_generated.rs`); диспатч игры — `crates/horizon-client/src/game/native_hooks/fire.rs:6` (`mod_api_fire_generated.rs`), модули — `native_hooks/mod.rs:122`, `game.rs:62`, `game/host/mod.rs:11`; wasm-граница — `crates/horizon-mod-wasm/src/lib.rs:34-36` (`wire_host_generated.rs`). **Расширять интерфейс можно штатно**; WASM-подписки пересекают границу по именам, `HookId` — процесс-локальные индексы, нативные моды компилируются под ревизию (`hooks/mod.rs:38-44`). Генератор сейчас_EMIT'ит только Rust/wire (`api-gen/src/surface/rust.rs`, `wire/`) — Lua-эмиттера нет, но каталог для него готов.

**Импорт модом:** крейт `horizon-mod-api` (имя библиотеки `mod_api`), `#[mod_api::horizon_mod]` на единственном `impl Hooks` подписывает мод ровно на реализованные хуки (`horizon-mod-api/src/lib.rs:15-33`). `horizon-hooks` — это другой шов (engine→Horizon-слой: `registry.rs`, `hud.rs`, `pages.rs`…), не мод-API.

**Диспатч конкретных хуков:**
- `use_item_on` (Part блока): декларация `crates/horizon-mod-vocab/src/hooks/block_use_item_on.rs:8-16` (`contract=replace, out=answer, scope=block, key=state`, server). Глобальный перехватчик `use_item_on_block`: `hooks/use_item_on_block.rs:10-17` (cancel, both). Точка игры: `crates/horizon-client/src/game/native_hooks/use_item_on_block.rs:11-19` → `fire_use_item_on_block`; вызовы из `game/items/use_hand.rs:88,95,205,377`.

- Тики: `block_entity_tick` (Part, `hooks/block_entity_tick.rs:24-31`, семантика `Changed/Unchanged`), `block_entity_ticks` (`game/native_hooks/base.rs:1039`), `server_tick`, `level_tick_pre/post`, `tick_block` — файлы в `hooks/`. ## 5. Сборка под aarch64-apple-ios

- Литерала `aarch64-apple-ios` в репозитории **нет** (grep = 0), но iOS-порт идёт на уровне cfg: `crates/horizon-dualsense/src/lib.rs:13-15`, `xbox/device.rs` (десятки `#[cfg(not(target_os = "ios"))]`), `crates/horizon-guest-stack/src/lib.rs:133,146,206,224-226` (`target_vendor = "apple"`).
- wasmtime: cranelift+pulley скомпилированы (`horizon-mod-wasm/Cargo.toml:22`), стратегия явно не выбирается, `macos_use_mach_ports` не настраивался. На iOS JIT запрещён — нужен принудительный Pulley; сейчас это не выражено ни одним cfg.
- C-зависимости: `mimalloc 0.1.52` + `libmimalloc-sys 0.1.49 (extended)` — `crates/horizon-threads/Cargo.toml:11-12`; патч на `third_party/libmimalloc-sys` (root `Cargo.toml:115-118`, обход MSVC-POPCNT бага v3); фича `windows-mimalloc` — `crates/horizon-game/Cargo.toml:38` (аллокатор гейтится под Windows). Прочий `third_party`: `wgpu-hal`, `naga` (root `Cargo.toml:2`). Кросс-сборка mimalloc под iOS не проверялась.
- Lua: `mlua`/`rlua`/`luajit` в манифестах **нет** — слой LuaJIT отсутствует полностью.

## 7. Риски и блокеры

1. **Шаг 4 (мутабельный ItemStack):** `BlockClick.stack: Option<&ItemStack>`, структура `Copy`, wasm-транспорт — снапшоты (`block/types.rs:418-441`). Мутабельность = смена контракта события (версия `hook_version`), затрагивает wire-кодоген и обе стороны; это не локальная правка.
2. **Шаг 3 (LevelRef в BE-тике):** событие без измерения; `host.dimension()` возвращает `&'static str` текущего `dim` и корректен только пока подмена уровня (`world/levels.rs`) активна. Добавление поля в событие — правка каталога + регенерация; `&'static str` в host-сигнатуре ограничивает динамику.
3. **Шаг 6 (copy_components):** loot-функции — закрытый match без реестра (`loot.rs:1520`); `copy_components` размазан по `game/blocks/spill.rs`. Новая функция = правка ядра + parity-харнесс, мод-расширения возможны только через JSON-инъекцию `loot_table_load`.
4. **Шаг 6 (торговля):** `Trades::load` читает только `minecraft`-namespace рута; как контент `.hmod` и миры попадают в `root`/`overlay.tag_kind("villager_trade")` — **не прослежено** (место вызова `Trades::load` не найдено за лимит инструментов). Валидатор, запрещающий `trade_set` в своём неймспейсе, **не локализован**; крейт `horizon-mods` из AGENTS.md в снапшоте отсутствует — карта AGENTS.md частично устарела.
5. **Шаг 1 (JSON до разбора):** универсального хука преобразования нет. `data_pack_files` покрывает только data-таблицы (не assets/blockstate); биом-модификаторы применяются на этапе сборки контента (`mod_content.rs:2682`), а ворлдген сохраняется в чанки (`vanillagen.rs:837`) — поздняя трансформация не перестроит уже сгенерированные чанки. Хук «после биомов и тегов, до разбора» потребует новой точки в `build_world_tables`/`prepare_server_reload`.
6. **Шаг 5:** `add_server_reload_listeners` уже есть (prepare-фаза); перенос публикации станций упирается в формат `ContentPart` (только рецепты, кап ~1 MiB, `lan/recipes.rs:334-352`) — нужен новый канал/тип载荷 и синхронизация `Trades`/`stations`.
7. **iOS:** нет таргет-конфига и явного Pulley (JIT на iOS запрещён), mimalloc — C-сборка с Windows-специфичным патчем; LuaJIT на iOS работает только интерпретатором (mlua vendored это учитывает, но производительность и сборка под aarch64-apple-ios не проверены). Единый источник для Lua-биндингов готов (каталог vocab), но эмиттера Lua в `api-gen` нет — его писать с нуля.
8. **Детерминизм:** исследованные пути чистые (BTreeMap/Vec), но `Trades` и словари рецептов местами на HashMap; перед шагом 1 нужен аудит обходов, влияющих на порядок RNG, по всему `worldgen/` и `crafting/` — не выполнен.
9. **Масштаб каталога:** 738 хуков, замороженные `catalog-order` ординалы; любые изменения контрактов существующих хуков ломают нативные моды до пересборки (WASM — по именам, устойчивее).

**Оставшиеся вопросы (не закрыты за лимит чтения):** место вызова `Trades::load` и путь тегов `.hmod` в него; точный валидатор `trade_set`; список `BasicFeature`; содержимое `fdshape`; поля сгенерированного события Part-хука `use_item_on`; наличие iOS-таргета в `.cargo/config.toml`.
